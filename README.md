# 수식 변환기 ver1.05

LaTeX·한글 수식 변환기입니다. PC 디자인은 유지하고 모바일 배치를 개선했습니다.
외부 라이브러리, 서버, 데이터베이스 없이 GitHub Pages에서 실행됩니다.

## GitHub Pages에 올리기

1. 이 폴더 안의 파일과 icons 폴더를 모두 저장소에 업로드합니다. index.html이 배포할 폴더의 맨 위에 있도록 합니다.
2. GitHub 저장소의 Settings → Pages에서 Deploy from a branch를 선택합니다.
3. 업로드한 브랜치(보통 main)와 /(root)를 선택하고 Save를 누릅니다.
4. 게시가 완료되면 Pages에 표시된 주소로 접속합니다.

이미 GitHub Pages가 설정된 저장소라면 파일 교체와 커밋만 하면 됩니다.
이 폴더는 독립 사이트용입니다. 기존 홈페이지가 있는 저장소의 루트에 index.html을 덮어쓰면 기존 홈페이지가 이 앱으로 바뀝니다. 기존 홈페이지를 유지하려면 별도 폴더에 넣고 해당 폴더 주소로 접속하세요.

## 아이콘

- favicon.ico: 브라우저 탭 아이콘
- icons/apple-touch-icon.png: iPhone·iPad 홈 화면 아이콘
- icons/icon-192.png / icon-512.png: 웹 앱 아이콘
- icons/icon-1024.png: 고해상도 아이콘
- site.webmanifest: 사이트 이름·실행 주소·홈 화면 아이콘 설정

아이콘은 내장 imagegen 도구로 제작했습니다. 제작 프롬프트 요약: 보라색 배경에 흰색 f(x)와 양방향 변환 화살표를 배치한 단순한 수학 앱 아이콘.
모든 아이콘 경로는 상대 경로이므로 GitHub Pages의 저장소별 하위 주소에서도 사용할 수 있습니다.
아이콘이 이전 모습으로 보이면 브라우저 캐시를 새로 고치거나 홈 화면 바로가기를 다시 추가하세요.

## 사용 및 저장

- 휴대폰에서는 기호 버튼과 이전·다음 입력칸 버튼을 이용할 수 있습니다.
- 긴 행렬은 수식 입력 영역 안에서 가로로 이동합니다.
- GitHub Pages 접속 시에는 사이트 파일을 불러오기 위한 인터넷 연결이 필요합니다. 서비스 워커를 통한 오프라인 캐싱 기능은 추가하지 않았습니다.
- 별도로 제공하는 단일 HTML 파일은 내려받아 오프라인으로 실행할 수 있습니다.
- 수식 작성 내용은 저장하지 않으므로 새로고침·종료 전에 코드를 복사하세요.

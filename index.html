02   코드 출력같은 수식, 두 가지 문법

사용 방법 · 호환성 · 검증 범위
  • 분수·근호 등의 버튼 → 점선 입력칸 선택 → 숫자·문자 입력. 선택한 수식에 버튼을 누르면 해당 구조로 감쌉니다. 선택이 없으면 지수·근호 버튼도 새 입력 틀을 만듭니다.
  • Tab / Shift+Tab: 입력칸 이동. 방향키: 글자 이동, 입력칸 경계에서는 틀 밖으로 이동. ‘틀 밖으로’로 분모·지수 등의 입력을 마치고 뒤에 이어 쓸 수 있습니다.
  • 텍스트 버튼 안에서는 일반 설명과 한글을 입력하세요. 수식 영역의 ^, _, / 키는 각각 지수·아래첨자·분수 틀을 만듭니다. LaTeX 원문을 붙여넣어 변환하는 기능은 없습니다.
  • 여러 줄은 ‘행렬·여러 줄’ 탭의 틀을 사용하세요. 정렬 수식의 두 번째 칸은 등호를 포함하여 입력하세요. 행렬 원소 안에도 수식 틀을 넣을 수 있습니다.
  • 한글 출력은 수식 편집기의 스크립트 입력 창에 붙여넣으세요. 본문에 붙여넣으면 수식 개체로 바뀌지 않습니다.
  • 외부 라이브러리·CDN·서버·저장소를 사용하지 않습니다. 이 HTML 파일은 오프라인으로 작동하며 새로고침하면 작성 내용이 초기화됩니다.
  • 브라우저의 시각적 수식은 자체 HTML/CSS 편집 표시입니다. LaTeX 및 한글의 최종 조판과 글꼴·간격이 다를 수 있습니다. 한글이 포함된 LaTeX는 한글을 지원하는 조판 환경이 필요합니다.
  • 검증: JavaScript 구문 검사, DOM 모의 실행 42개 점검 및 수식 틀 63종의 양방향 구조 보존 검사 통과. 브라우저에서의 클릭·터치·복사·화면 배치는 자동 실행 검증하지 못했습니다.
  • 실제 한컴오피스 한글에서의 붙여넣기, 실제 아이패드 Safari·한글 IME 기기 검증은 수행하지 않았습니다. 한글 출력의 모든 버전 호환성을 보장하지 않습니다.
